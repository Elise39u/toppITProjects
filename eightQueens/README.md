# EIGHT QUEENS PROBLEM
This is my take on the populair eight queens coding problem. In this challange the following rule are stated.        
You have to place 8 queens on a 8x8 chess board. A queen is not allowed to see an other queen for: Horizontal, Vertical and Diagonally.         
Can you solve the issues and place 8 queens on the board before they flew each other into the hair        

# Coding build 
This project is made in pure JS and HTML as a relearner and refresher within regards to coding.       
Further more the project has support of the Chessboard libary and the live-server NPM module
